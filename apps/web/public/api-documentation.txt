Post Engineer API
================================================================================

Base URL:        https://post-engineer.com
Development URL: http://localhost:3434
OpenAPI spec:    https://post-engineer.com/openapi.json
MCP server:      npx -y post-engineer-mcp@latest (env POST_ENGINEER_API_KEY)

The OpenAPI spec lists every endpoint below. It is generated from the MCP
parity mapping (apps/mcp/src/__tests__/parity-endpoint-tools.json) by
`node apps/web/scripts/generate-openapi.mjs`, with request and response
schemas from apps/web/scripts/openapi-schemas.mjs. Some nested items (social
accounts, metrics rows) are typed as free-form objects.

================================================================================
AUTHENTICATION
================================================================================

Create an API key in the dashboard (https://post-engineer.com/recipes) or
through POST /api/api-keys (web session only). Keys start with `pe_live_`
and are shown once.

Send the key on every request, either way:

  Authorization: Bearer pe_live_xxxxxxxx
  X-API-Key: pe_live_xxxxxxxx

A key can be limited to specific personas. A missing key returns 401
"Authentication required."; an invalid key returns 401 "Invalid API key.".

================================================================================
RESPONSES AND ERRORS
================================================================================

- JSON bodies. Failures carry success:false and an error message.
- Routes return a flat { "success", ... } payload.
- 400 invalid, over-length or conflicting input (nothing is truncated or
  coerced silently). 401 bad key. 402 BETA_ACCESS_REQUIRED: the account has
  not joined the closed beta yet, publishing and scheduling are blocked
  (request access on Discord: https://discord.gg/ukmCXMCDJ).
  404 unknown id. 409 conflict. 410 gone: an expired upload. 429 rate
  limited: retry with backoff. 5xx transient: retry with backoff. Each
  operation's statuses are in the spec.
- Upload, destructive and fan-out routes are rate limited per caller.

================================================================================
PUBLISHING
================================================================================

Post Engineer does not generate media. Make the video or image with your own
tool, then publish it:

1. POST /api/videos/upload-url                     create a staged upload
2. PUT the file to the returned signed URL
3. POST /api/videos/uploads/{uploadId}/complete    mark the upload complete
4. POST /api/media/publish-existing                publish now (mode "asap")
   or schedule once at publishAt (mode "scheduled", 3h to 30d ahead)

POST /api/upload-content publishes a small video directly in one multipart
request. Read the result with GET /api/schedule/slots/{slotId}.

================================================================================
SOCIAL ACCOUNTS
================================================================================

Supported: YouTube, Instagram, LinkedIn, Threads, Facebook Pages, Bluesky,
3Speak, Rumble, Telegram. Connect via POST /api/account/connect-url (returns
an https auth_url to open in a browser), POST /api/bluesky-connect (app
password), POST /api/threespeak-connect (Hive posting key), POST
/api/rumble-connect (access token issued by emailing bd@rumble.com) or POST
/api/telegram-connect (a @BotFather bot token, the chat ID or @username, and
chatType channel or group: a channel bot must be an administrator who can
post, a group bot a member allowed to send). Then map accounts to a persona
with PUT /api/persona/publishing-accounts.

================================================================================
MARKETPLACES (RapidAPI, MCP Registry)
================================================================================

The same API key works everywhere.

- RapidAPI: send your Post Engineer key in Authorization: Bearer pe_live_...
  next to the X-RapidAPI-Key header. RapidAPI forwards it; without it the API
  returns 401.
- MCP Registry: io.github.Ryan-Carloso/post-engineer (npm post-engineer-mcp),
  configured with POST_ENGINEER_API_KEY.
